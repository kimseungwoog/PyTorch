# TradeDeck 설계

토스증권 Open API 로 국내 주식을 거래하는 개인용 트레이딩 앱. 웹으로 먼저 만들고 같은 코드를 안드로이드 앱으로 옮긴다.

> 참고하려던 에펨코리아 글(10583250853)은 작업 환경에서 접속이 막혀 읽지 못했다.
> 아래 설계는 그 글이 아니라 일반적인 트레이딩 앱 구성을 기준으로 잡았다. 글 내용을 받으면 3장 기능 목록부터 다시 맞춘다.

## 1. 목표와 원칙

1. **돈을 잃게 만드는 실수를 막는다.** 모의투자가 기본이고, 실계좌 주문은 여러 단계를 거쳐야 켜진다.
2. **한 손으로 빠르게.** 휴대폰 화면이 기준이다. 종목 → 차트·호가 → 주문까지 두 번 누르면 닿는다.
3. **공급자를 갈아 끼운다.** 시세와 주문을 인터페이스 뒤에 두어 모의 ↔ 토스증권을 설정만으로 바꾼다.

## 2. 구조

```
[웹 / 안드로이드 앱]  ──REST·WebSocket──▶  [내 서버]  ──REST·WebSocket──▶  [토스증권 Open API]
   React (web/)                              Node (server/)
                                             ├─ MarketProvider : mock | toss
                                             ├─ Broker         : paper | toss
                                             └─ 위험 관리 (주문 한도 등)
```

**서버를 반드시 거치는 이유**

- 토스증권 API 는 `client_secret` 으로 토큰을 받는다. 이 값을 앱이나 브라우저에 넣으면 누구나 꺼내 갈 수 있다.
- 호출하는 쪽 IP 를 토스증권에 미리 등록해야 한다. 휴대폰은 IP 가 계속 바뀌므로 고정 IP 를 가진 서버가 대신 호출해야 한다.
- 호출 한도(시세 초당 10회, 주문 초당 6회)를 한 곳에서 관리할 수 있다.

**폴더**

| 폴더 | 내용 |
| --- | --- |
| `shared/` | 서버·웹이 함께 쓰는 타입, 호가 단위, 봉 계산 |
| `server/src/market/` | 시세 공급자 (`mock.ts` 모의 시세) |
| `server/src/broker/` | 주문 공급자 (`paper.ts` 모의투자) |
| `server/src/toss/` | 토스증권 클라이언트와 연결 점검 스크립트 |
| `web/src/` | 화면 |

## 3. 기능

### 지금 들어 있는 것 (1단계)

| 화면 | 기능 |
| --- | --- |
| 종목 | 실시간 현재가·등락률, 검색, 관심 종목 |
| 거래 | 봉 차트(1분~일), 이동평균선 5·20·60, 거래량, 10단계 호가, 호가를 눌러 주문가 입력 |
| 주문 | 지정가·시장가, 호가 단위 증감, 비율 버튼(10%~최대), 주문 전 확인 창 |
| 자산 | 총자산, 예수금, 평가·실현 손익, 보유 종목 |
| 주문 내역 | 체결·미체결 목록, 미체결 취소 |

모의투자 규칙: 시장가는 현재가에 즉시 전량 체결, 지정가는 현재가가 주문가에 닿으면 전량 체결. 수수료 0.015%, 매도 세금 0.15% 를 기본값으로 넣었고 `.env` 에서 바꾼다(실제 요율은 확인 필요).

### 다음에 넣을 것

- **가격 알림**: 목표가 도달, 급등락, 체결 시 푸시 알림
- **자동 주문**: 손절·익절 묶음 주문, 분할 매수·매도
- **매매 일지**: 주문마다 이유를 적고, 승률·손익비를 자동 집계
- **보조 지표**: RSI, MACD, 볼린저 밴드, 차트에 평단가·미체결 주문 선 표시
- **미국 주식**: 통화가 섞인 자산 합산, 환율 반영

## 4. 서버 API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/status` | 시세·주문 공급자, 실계좌 여부, 수수료율, 주문 한도 |
| GET | `/api/stocks` | 종목 목록 |
| GET | `/api/quotes` | 전 종목 현재가 |
| GET | `/api/candles/:symbol?interval=5m&count=300` | 봉 |
| GET | `/api/orderbook/:symbol` | 호가 |
| GET | `/api/account`, `/api/holdings`, `/api/orders` | 계좌, 보유 종목, 주문 내역 |
| POST | `/api/orders` | 주문 |
| DELETE | `/api/orders/:id` | 주문 취소 |
| WS | `/ws` | 서버→앱: `quote`, `orderbook`, `order` / 앱→서버: `subscribe` |

## 5. 토스증권 연동

공개 자료로 확인한 내용(공식 문서 사이트는 작업 환경에서 막혀 검색 결과로만 확인):

| 항목 | 내용 | 확실한 정도 |
| --- | --- | --- |
| 키 발급 | 토스증권 WTS > 설정 > Open API 에서 `client_id`, `client_secret` 발급, 허용 IP 등록 | 여러 자료가 일치 |
| 토큰 | `POST https://openapi.tossinvest.com/oauth2/token` (`grant_type=client_credentials`) | 여러 자료가 일치 |
| 계좌 헤더 | 계좌·주문 요청에 `X-Tossinvest-Account` | 여러 자료가 일치 |
| 주문 | `POST /api/v1/orders`, `/api/v1/orders/{id}/modify`, `/api/v1/orders/{id}/cancel` | 검색 결과로 확인 |
| 계좌 | `GET /api/v1/accounts`, `GET /api/v1/holdings` | 검색 결과로 확인 |
| 종목 | `GET /api/v1/stocks?symbols=005930` | 검색 결과로 확인 |
| 현재가·호가·봉 경로 | 자료마다 달라 **미확정** | 직접 확인 필요 |
| 실시간 | `wss://openapi-ws.tossinvest.com/ws/v1`, 계정당 연결 2개·연결당 구독 100개 | 자료가 엇갈림, 확인 필요 |
| 호출 한도 | 시세 초당 10회, 주문 초당 6회 (09:00~09:10 은 3회) | 검색 결과로 확인 |

**연결 순서**

1. `.env` 에 키를 넣고 `npm run toss:probe` 를 실행한다. 조회만 하고 주문은 보내지 않는다. 응답 원문이 출력된다.
2. 그 출력으로 필드 이름을 확정해 `server/src/toss/` 에 시세 어댑터(`MarketProvider`)를 만든다.
3. **실제 시세 + 모의투자** 조합으로 며칠 쓴다. 이 단계에서는 실제 돈이 움직이지 않는다.
4. 주문 어댑터(`Broker`)를 만들고 1주 단위 소액으로 실계좌를 검증한다.

`client.ts` 에는 토큰 발급·캐시, 그룹별 호출 한도, 401 재발급이 들어 있다. 주문(POST)은 중복 주문을 막기 위해 자동 재시도하지 않는다.

## 7. 안드로이드로 가는 길

화면은 처음부터 휴대폰 폭 기준으로 만들었고, 넓은 화면에서는 네 칸으로 펼쳐진다.

- **권장: Capacitor 로 감싸기.** 지금 웹 코드를 그대로 안드로이드 앱에 넣는다. 푸시 알림, 생체 인증은 플러그인으로 붙인다. 화면을 두 번 만들지 않아도 된다.
- 대안: Kotlin 으로 새로 작성. 가장 매끄럽지만 화면을 전부 다시 만들어야 한다. 서버와 `shared/` 의 규칙은 그대로 쓴다.

앱으로 가기 전에 필요한 것: 고정 IP 를 가진 서버(집 PC 또는 클라우드), HTTPS, 로그인.
